How it works

Six steps, about two minutes, and every one of them is traceable in the results.

  1. 1ResolveSeeds, typed in or imported from a reference manager, are found in PubMed, or in Europe PMC for preprints.
  2. 2PlanThe LLM turns the question and seeds into inclusion criteria and search queries.
  3. 3CollectSeven channels gather candidates, the web agent among them. Each records where it came from.
  4. 4RankEmbedding similarity to each seed and to the question, fused with citation signals.
  5. 5JudgeThe strongest ~130 candidates are graded against the criteria, each with a verified quote.
  6. 6ExploreTrials and web context for the top results, and a map of themes and citations.
